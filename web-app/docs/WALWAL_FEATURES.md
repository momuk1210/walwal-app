# WalWal (왈왈) 앱 구현 현황 및 프로세스 문서

이 문서는 지금까지 WalWal 프로젝트에 구현된 기능, 앱의 흐름(프로세스), 그리고 적용된 주요 기술 스택을 기록한 문서입니다. 새로운 작업을 시작하기 전에 이 문서를 바탕으로 기존 구조를 파악합니다.

## 1. 기술 스택 (Tech Stack)
- **프레임워크**: React + Vite (TypeScript)
- **스타일링**: 순수 CSS (`src/styles/*.css`)
- **다국어 지원**: 자체 구현한 `LanguageContext` 및 `translations.ts` (한국어, 영어, 일본어, 스페인어 지원)
- **인증(Auth)**: Firebase Authentication (Google 로그인, 익명 로그인)
- **아이콘**: `lucide-react`

---

## 2. 앱 실행 프로세스 (App Flow)
앱의 전반적인 상태는 `App.tsx`에서 관리하며 크게 3단계의 화면 상태(State)를 가집니다.

1. **인증 화면 (`appState === 'auth'`)**
   - 진입점: `AuthView.tsx`
   - 기능: 걷는 강아지 애니메이션(GIF), 'Google로 계속하기', '게스트로 둘러보기(익명 로그인)' 기능 제공.
   - 프로세스: Firebase 로그인이 완료되면 `onAuthStateChanged` 훅에 의해 자동으로 다음 화면으로 전환됨.

2. **결제 및 유도 화면 (`appState === 'paywall'`)**
   - 진입점: `PaywallView.tsx`
   - 기능: WalWal 앱은 **100% 유료 구독 전용 서비스**입니다. (무료 티어 없음)
   - 프로세스: 첫 가입자는 7일 무료 체험을 시작(결제 수단 등록)해야만 앱의 메인 기능에 접근할 수 있습니다. 우회 경로는 존재하지 않으며, 이 화면을 통과해야만 상태가 `'main'`으로 전환됩니다.

3. **메인 앱 화면 (`appState === 'main'`)**
   - 진입점: `BottomNav`를 포함한 탭 기반 레이아웃 (`App.tsx` 내에서 렌더링).
   - 하단 탭(Navigation): AR(번역기), 레이더, 피드, 번개(커뮤니티), 프로필.

## 3. 주요 구현 기능 상세

### 3.1. 프로필 관리 (`ProfileView.tsx`)
- **다중 반려견 관리**: 강아지 프로필을 여러 개 등록하고 탭(가로 스크롤 스와이프 기능 적용)을 통해 스위칭할 수 있음.
- **반려견 추가/수정 기능**: 우측의 `+` 버튼으로 새 프로필 추가, 우측 상단 수정 아이콘으로 기존 프로필 수정 가능.
- **프로필 요약 카드**: 설정한 강아지 정보(이름, 견종, 나이, 성별) 및 카메라 연동 더미 아바타.
- **설정 접근**: 프로필 화면의 상단 헤더 우측에 **톱니바퀴(⚙️)** 버튼을 두어 `SettingsView`로 진입하도록 설계됨.

### 3.2. 환경 설정 및 앱 관리 (`SettingsView.tsx`)
프로필 화면을 덮는 전체 화면 오버레이 형태로 렌더링됩니다.
- **앱 설정(언어 변경)**: 한국어, 영어, 일본어, 스페인어 중 선택 가능하며 선택 즉시 전역 `LanguageContext`에 반영되어 앱 내 모든 텍스트가 번역됨.
- **권한 및 알림 관리**: 카메라, 마이크, 위치, 각종 알림에 대한 토글(Toggle) 스위치 UI 제공 (현재는 더미 상태).
- **계정 관리**: Firebase 연동 로그아웃 및 회원 탈퇴(계정 삭제) 로직 구현. 탈퇴 시 재인증(Recent Login) 필요 예외 처리 완비.
- **고객 지원(약관)**: `LegalView`와 연결되어 약관 화면 렌더링.

### 3.3. 고객 지원 및 약관 화면 (`LegalView.tsx`)
- **자주 묻는 질문 (FAQ)**: Q&A 형태의 레이아웃.
- **이용약관 / 개인정보 처리방침**: 텍스트 기반의 정책 안내 레이아웃.
- **특징**: `SettingsView` 위에 또 다른 오버레이로 렌더링되며, 이 화면의 내용 역시 `translations.ts`의 `legal` 영역을 통해 완벽한 다국어 번역을 지원.

## 4. 향후 작업 시 참고 사항 (Guidelines)
1. **100% 유료 구독 모델 고수**: WalWal은 프리미엄 전면 유료 서비스입니다. 앱 내에 '무료 버전'을 가정한 로직이나 안내 문구(예: '기본 기능은 무료', 'n마리까지 무료')를 절대 넣지 않도록 주의합니다.
2. **다국어 추가 시**: `src/i18n/translations.ts` 파일의 `TranslationSchema` 타입에 반드시 항목을 정의한 후, `ko`, `en`, `ja`, `es` 네 곳 모두에 해당 키(Key)와 번역본을 누락 없이 추가해야 합니다.
3. **CSS 클래스**: UI 요소 수정 시 인라인 스타일보다는 가급적 `src/styles/common.css` 등 기존 CSS 시스템 내에서 클래스를 재활용합니다.
4. **인증 관련 수정 시**: `firebase.ts`를 활용하고 `App.tsx`의 `onAuthStateChanged` 상태 변화 프로세스를 염두에 두고 작업해야 합니다.
